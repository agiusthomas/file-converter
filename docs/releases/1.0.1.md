# Glacier File Converter 1.0.1

A small update that adds subtle **Soft Detent** sounds to the conversion wheel and a short confirmation when your conversions finish. This release is **1.0.1, build 5**.

## What's new

- A soft opening cue and quiet dial clicks as you move between wheel options using drag, mouse or keyboard. Rapid movement is limited so sounds never pile up.
- One success cue per fully successful manual batch, including main-window conversions and recipes. Independently started batches confirm separately. Failed/cancelled batches, previews and watched folders stay silent.
- **Settings → Sound effects** offers mute, volume and **Preview sounds**. Sounds start at 30% and follow your Mac's output volume/mute setting.
- The other two sound directions, **Glacier Glass** and **Warm Minimal**, are saved with their playable previews in the [source repository](https://github.com/agiusthomas/file-converter/tree/v1.0.1/docs/sounds) for later comparison.
- Queue submission and completion bookkeeping keeps sound feedback accurate when batches overlap or cancellation happens during submission.

- **[Alternative ZIP](https://github.com/agiusthomas/file-converter/releases/download/v1.0.1/Glacier-File-Converter-1.0.1.zip)**.
- **[SHA-256 checksums](https://github.com/agiusthomas/file-converter/releases/download/v1.0.1/Glacier-File-Converter-1.0.1-SHA256SUMS.txt)**.

App and DMG are Developer ID signed, notarized by Apple and stapled. Requires **Apple silicon and macOS 13 or later**. Existing settings, history, recipes, folder permissions and installed engines carry forward.

If upgrading from the older **File Converter.app**, quit it, install **Glacier File Converter.app**, then remove the old app copy before launching the new one. The filenames differ, so Finder will not replace the old copy automatically. Preserve the app's Library data and reselect Login Items if it still points at the old filename. Earlier downloads remain unchanged.
