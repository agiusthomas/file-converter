# Glacier File Converter 1.0.0

The first official release of **Glacier File Converter** brings together the native macOS conversion tools developed through the earlier File Converter previews, the latest Finder-wheel fixes, and the new Glacier name and faceted ice icon. Your existing settings, recipes, history and installed engines carry forward. The familiar blue palette, workspace and conversion-wheel design remain intact.

## Download and install

- **[Download the DMG](https://github.com/agiusthomas/file-converter/releases/download/v1.0.0/Glacier-File-Converter-1.0.0.dmg)** — open it and drag **Glacier File Converter** to **Applications**.
- **[Alternative ZIP](https://github.com/agiusthomas/file-converter/releases/download/v1.0.0/Glacier-File-Converter-1.0.0.zip)** — unzip and move the app to Applications.
- **[SHA-256 checksums](https://github.com/agiusthomas/file-converter/releases/download/v1.0.0/Glacier-File-Converter-1.0.0-SHA256SUMS.txt)**.

App and DMG are Developer ID signed, notarized by Apple and stapled. No developer tools or security-setting changes are needed. Requires an **Apple-silicon Mac (M1 or newer), macOS 13 or later**. This release was exercised on macOS 26.5.1; execution on macOS 13 and a clean offline second Mac remains unverified. Intel builds are not provided.

**Upgrading from File Converter:** quit the old app from its menu bar menu, install **Glacier File Converter.app**, then remove the old **File Converter.app** copy before launching the new one. Finder will not automatically replace an app with a different filename. Keep the app's Library data: bundle identifiers and storage locations are preserved. If Login Items still points to the old filename, reselect the new app. Earlier preview downloads remain unchanged.

## New since the 0.2.1 preview

- **Glacier branding throughout:** two-line sidebar heading, full application name in windows, menus, tooltips, accessibility descriptions and Finder Services; matching faceted ice app icon and adaptive monochrome sidebar/menu-bar marks.
- **Accurate version information:** Settings reads version and build directly from the app metadata. This release is **1.0.0, build 4**.
- **Responsive Finder wheel:** highlights track the pointer even when native drag callbacks are absent. Releasing over a valid action submits it once; duplicate native/polled callbacks cannot start the same conversion twice. Escape, neutral-center drops and drops outside the wheel cancel correctly.
- **Conversions stay in the background:** direct wheel actions save results beside the originals without opening the workspace. Actions needing additional options retain the workspace setup flow.
- **Updated distribution:** renamed DMG/ZIP/checksum files, installer instructions, app-icon packaging checks, generated Xcode project and CI verification.
- **Regression coverage:** automated checks cover sector tracking, missing release callbacks, duplicate submissions, cancellation, validated JPG outputs and background publication.

## Included features

- **Images:** JPG, PNG, WebP, HEIC, TIFF, AVIF, BMP and image-to-PDF outputs where supported; resize, crop, quarter-turn rotation, backgrounds, multiple exports, quality/target-size controls and image GPS-property removal. Still WebP encoding is bundled. Input animation, metadata and high-bit-depth support vary by format.
- **PDF:** page previews and ordering, removal and rotation, merge/split, page-image export, image-to-PDF, selectable-text extraction, local OCR, searchable PDFs and password protection. PDF size reduction rasterizes/downsamples pages and removes interactive features, selectable text and signatures; review the app's notices before using it.
- **Native audio/video:** compatible H.264/HEVC MP4, AAC M4A and PCM WAV; trimming, speed, mute, matching joins, resize/crop/rotation, audio extraction and frame export. Availability depends on the actual input and macOS encoders.
- **Archives:** ZIP, TAR, TAR.GZ and tested 7z creation/extraction, selective extraction and preservation of relative paths. Unsafe paths, links and excessive expansion are rejected. RAR reading depends on the system library and remains unqualified.
- **Text and subtitles:** encodings, line endings, CSV/TSV quoting and textual leading zeros, plus SRT/VTT conversion and timing adjustments.
- **Mac workflows:** drag-and-drop workspace, configurable Shift/Option/Control Finder wheel, Finder Service, Shortcuts conversion action, menu-bar access, optional login launch, previews, activity/history and explicit retry.
- **Repeatable preparation:** saved multi-step recipes with multiple exports, recipe editor and JSON import/export, optional watched folders, result shelf, drag-out/copy/reveal and batch naming/subfolder controls.
- **CLI:** file inspection, capabilities/actions, conversion, typed operation options, recipes and job recovery; verified outputs carry measured properties, hashes and engine information.

Original files remain intact. Results save beside originals unless a destination is selected, and existing output names receive a number. Conversions run locally; network access is used for explicit optional engine downloads.

## Optional Media engine

The signed app includes the existing catalog entry for **[Media 0.1.2](https://github.com/agiusthomas/file-converter/releases/tag/engine-media-v0.1.2)**, an independently built FFmpeg 8.1.2 qualification preview with corresponding source, build records and license notices. Install it explicitly from **Engines**. The interface provides compatibility/sizes/notices, progress, cancellation/retry, local import, update, rollback and removal. Running jobs retain their pinned engine versions.

The production sandboxed worker rechecks publisher signatures and file hashes, stages data in its container, and waits for child termination during cancellation. No signing, sandbox or library-validation checks have been relaxed. The Media pack remains a separate qualification preview; its qualified FLAC and H.264/AAC paths do not imply complete MP3/Opus/VP9 or advanced-track coverage.

## Verification and known limits

Local verification covers **73 passing tests with zero failures or skips**, including native media/OCR, supplemental external-tool tests and the native window-server wheel check. Supplementary developer-installed tools are used only by tests and are not shipped or treated as installed production packs. The release build passed fresh signature, notarization, Gatekeeper, archive/checksum and signed-app/XPC Media qualification checks; exact results are recorded in [distribution evidence](https://github.com/agiusthomas/file-converter/blob/v1.0.0/docs/evidence/app-1.0.0-release.json).

The Glacier sidebar was inspected at minimum window size in light and dark appearance, and existing job history remained accessible after the rename. The wheel fixes have automated regression coverage; physical Finder dragging across displays, Spaces and screen edges still needs broader manual qualification.

Documents (LibreOffice/Pandoc), Ebooks (Calibre), Transcription (whisper.cpp/models) and PDF structural-optimization packs remain unpublished. Their adapters do not make those conversions delivered. The complete media corpus, advanced track/subtitle/HDR workflows, clean-machine/minimum-OS checks, full accessibility audit, large-batch responsiveness and the remaining crash/storage/grant/activation fault matrix are still unfinished. **1.0.0 is the user-requested official release of the available feature set; the larger seven-milestone expansion remains in progress.**
