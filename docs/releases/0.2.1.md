# File Converter 0.2.1 Preview

A partial preview of the ongoing seven-milestone expansion for Apple-silicon Macs. This release adds a real downloadable Media engine and native engine management. It does not complete the original expansion or any milestone's full acceptance gate.

## Install

Download **File-Converter-0.2.1.dmg**, open it, drag **File Converter** to **Applications**, then eject the disk image. Quit an existing copy from its menu bar menu before replacing it. The ZIP is an alternative app download. App and DMG are Developer ID signed, notarized and stapled; no security-setting changes or developer tools are needed. Compare downloads against **File-Converter-0.2.1-SHA256SUMS.txt** if desired.

Targets macOS 13+ on Apple silicon. Actual execution was qualified on macOS 26.5.1; macOS 13 execution and clean offline installation on a second Mac remain unverified.

## Changes

- **Downloadable Media 0.1.2 qualification preview:** independently built, pinned FFmpeg 8.1.2 with relocatable arm64 libraries, verified signatures, complete corresponding source, build records and license notices. In **Engines**, review notices and choose **Download and install**. No engine is downloaded automatically. Installed conversions process files locally.
- **Native engine controls:** compatibility and size information, download progress/cancellation/retry, local import, update, rollback, source/license disclosure and removal. Running work keeps its immutable runtime version; removal waits until it is no longer in use.
- **Sandboxed engine execution:** the production XPC worker uses an immutable executable store, stages conversion data inside its container, rechecks runtime signatures/hashes and acknowledges cancellation after child termination/cleanup. Signing, sandbox and library-validation checks remain enforced.
- **Preserved behavior:** SwiftUI/AppKit, Glacier, Finder gestures, original files and legacy image/CLI behavior remain in place. Version 0.2.0 and its published artifacts remain available unchanged.

## Verification

64 local tests passed with native media/OCR and supplemental external-engine integration checks enabled. Independently packaged FFmpeg passed actual Developer ID signed-app/XPC audio/video conversion, independent output decoding, original integrity, real-version update/rollback, tamper rejection, observed-child cancellation and deferred removal/reclamation. A real catalog download was interrupted after receiving bytes, then retried and installed. Native window installation/import/update/rollback/removal and a downloaded-pack conversion passed.

Developer-installed tools used in supplemental tests are separate from the downloadable pack evidence. See [exact runtime evidence](https://github.com/agiusthomas/file-converter/blob/v0.2.1/docs/FFMPEG_CHECKPOINT.md) and [implementation status](https://github.com/agiusthomas/file-converter/blob/v0.2.1/IMPLEMENTATION.md).

## Still unfinished

- The Media runtime qualifies FLAC and H.264/AAC paths. LAME MP3, Opus and VP9 dependencies, advanced track/subtitle/playback workflows and the complete media corpus remain required.
- Documents (LibreOffice/Pandoc), Ebooks (Calibre), Transcription (whisper.cpp/models) and PDF structure packs remain unpublished. Their adapters do not make those features delivered.
- Minimum-OS and clean offline host testing, the complete crash/storage/grant/interrupted-activation failure matrix, large-batch responsiveness, physical Finder gestures and full accessibility/appearance acceptance remain open.
- Other advanced workflows and milestones remain on the [continuation plan](https://github.com/agiusthomas/file-converter/blob/v0.2.1/docs/CONTINUATION_PLAN.md).

The Media runtime remains a qualification preview. Notarization establishes distribution trust and does not establish feature or milestone completion.
