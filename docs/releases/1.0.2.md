# Glacier File Converter 1.0.2

Sound effects now default to **100% volume**. This release is **1.0.2, build 6**.

## What's changed

- New sound settings start at 100%, following your Mac's output volume and mute setting.
- Existing saved volume and mute preferences carry forward. Adjust them in **Settings → Sound effects**.
- Playback initialization and the fallback for invalid volume values use the same 100% default.
- Future releases follow the requested sequence: 1.0.2, 1.0.3, …, 1.0.9, 1.1.0.

## Download and update

- **[Download the DMG](https://github.com/agiusthomas/file-converter/releases/download/v1.0.2/Glacier-File-Converter-1.0.2.dmg)** — quit Glacier File Converter, open the DMG, drag the app to Applications and confirm replacement.
- **[Alternative ZIP](https://github.com/agiusthomas/file-converter/releases/download/v1.0.2/Glacier-File-Converter-1.0.2.zip)**.
- **[SHA-256 checksums](https://github.com/agiusthomas/file-converter/releases/download/v1.0.2/Glacier-File-Converter-1.0.2-SHA256SUMS.txt)**.

App and DMG are Developer ID signed, notarized by Apple and stapled. Requires **Apple silicon and macOS 13 or later**. Existing settings, history, recipes, folder permissions and installed engines carry forward.

If upgrading from **File Converter.app**, quit it, install **Glacier File Converter.app**, then remove the old app copy. The filenames differ, so Finder will not replace the old copy automatically. Preserve the app's Library data and reselect Login Items if it still points at the old filename. Earlier downloads remain unchanged.
