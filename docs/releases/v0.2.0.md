# File Converter 0.2.0 Preview

The first downloadable preview of the expanded local file utility for macOS. The app and DMG are Developer ID signed and notarized by Apple.

## Install

Requires **macOS 13 or later on an Apple-silicon Mac (M1 or newer)**.

1. Download **File-Converter-0.2.0.dmg** below.
2. Open it and drag **File Converter** to **Applications**.
3. Eject the disk image, then open the app from Applications.

No Xcode or command-line tools are needed. The ZIP is an alternative app download; `SHA256SUMS.txt` contains both download checksums. See the [installation guide](https://github.com/agiusthomas/file-converter/blob/v0.2.0/docs/INSTALLATION.md) for first use, updates, and removal.

## Included

- Image conversion with still WebP, resize/crop/rotate, multiple outputs, and measured size limits.
- PDF page arrangement, merge/split, page-to-image and image-to-PDF, text extraction, local OCR, searchable PDF, and password tools.
- Native compatible audio/video exports and file-preparation tools.
- ZIP/TAR/TAR.GZ and tested 7z operations; text encoding, CSV/TSV, and SRT/VTT conversion.
- Persistent jobs, explicit interruption recovery, collision-free output naming, saved recipes, an optional Finder wheel, watched folders, and a result shelf.
- A Glacier workspace and a shared CLI/worker foundation. Originals remain untouched by conversion jobs.

## Preview limits

Optional Media, Documents, Ebooks, and Transcription packs are **not yet published**. Actions requiring them are unavailable. Native media support depends on the input and macOS; RAR reading is not qualified. PDF image-downsampling compression removes text and interactive content, as disclosed in the app.

The seven-milestone expansion is still in progress. This preview does not declare its release gates complete: clean-Mac/macOS 13 acceptance, physical Finder gestures, broader format coverage, accessibility, and several advanced features remain open. See [capabilities](https://github.com/agiusthomas/file-converter/blob/v0.2.0/docs/CAPABILITIES.md), [verification evidence](https://github.com/agiusthomas/file-converter/blob/v0.2.0/IMPLEMENTATION.md), and the [roadmap](https://github.com/agiusthomas/file-converter/blob/v0.2.0/docs/ROADMAP.md).

## Verification

The 58-test suite passed locally, including the opt-in native media/OCR and external-engine integration checks. The signed app passed a real sandboxed-worker inspection and image conversion. The release packaging checks signatures, notarization tickets, Gatekeeper acceptance, and disk-image integrity. Third-party notices are bundled in the app and documented in the source.
