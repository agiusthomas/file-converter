# Project instructions

## Releases

Use the existing checkout and follow `docs/RELEASING.md` for release preparation and publication.

For every app release, increment the last version digit by one: `1.0.1` → `1.0.2` → … → `1.0.9` → `1.1.0`. After the last digit reaches 9, reset it to 0 and increment the middle number. Also increment the internal bundle build number. Preserve existing published artifacts.
